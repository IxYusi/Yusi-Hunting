# Yusi's Hunting

Built on [ars_hunting](https://github.com/Arius-Scripts/ars_hunting) by Arius Scripts (Apache License 2.0).
Modified by Yusi.

**Changes from the original**

-   Animals are spawned and tracked by the server, so every player in a zone sees the same animals.
-   Animal updates are sent only to players inside the zone.
-   Harvest loot is picked on the server and each animal can only be skinned once.
-   New on-screen mission timer (HTML overlay) replacing the text UI.
-   Skinning skill check settings changed, boar bounty removed, cooked meat item updated.
-   Code cleanup and bug fixes.

The original license is kept in `LICENSE`. The original README follows.
